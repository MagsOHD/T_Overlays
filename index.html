📖 Comment utiliser dans OBS

1. Ouvrez OBS/Streamlabs
2. Ajouter une Source → Navigateur
3. URL locale : Copiez le chemin complet d'un overlay (ex: file:///chemin/vers/overlays/alerts/index.html)
4. Largeur: 1920, Hauteur: 1080
5. Cochez "Actualiser le navigateur quand la scène devient active"

⚙️ Configuration

Éditez le fichier config.json à la racine pour personnaliser :
- Vos réseaux sociaux
- Les couleurs du thème
- Les messages d'alertes
- La durée d'affichage
- Les volumes des sons

🎵 Sons

Ajoutez vos fichiers audio dans assets/sounds/:
- follow.mp3
- sub.mp3
- donation.mp3
- raid.mp3
- bits.mp3

Voir assets/sounds/README.md pour plus d'informations.
