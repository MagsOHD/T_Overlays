🌸 Un design doux et accueillant

Ces overlays sont conçus avec des couleurs pastel apaisantes et une approche centrée sur le bien-être. Chaque élément est pensé pour créer un espace chaleureux et inclusif.

⚙️ Configuration

Personnalisez tout dans config.json :

  • Vos réseaux sociaux
  • Les messages d'alertes
  • Les couleurs du thème
  • La durée des animations

📖 Utilisation dans OBS

1. Ajouter une source → Navigateur
2. URL : file:///chemin/vers/overlays/nom-overlay/index.html
3. Dimensions : 1920x1080
4. Cocher "Actualiser quand la scène devient active"
