🌸 Design organique et accueillant

Ces overlays utilisent des formes organiques (blobs) et des couleurs pastel apaisantes pour créer une ambiance cozy et bienveillante. Chaque animation est pensée pour être douce et non intrusive.

⚙️ Configuration

Personnalisez tout dans config-organic.json :

  • Vos informations et réseaux sociaux
  • Les messages pour chaque scène
  • Les paramètres des alertes (durée, sons, messages)
  • Les couleurs du thème

📖 Utilisation dans OBS/Streamlabs

1. Ajouter une source → Navigateur
2. URL locale : file:///chemin/complet/vers/scenes/nom-scene/index.html
3. Dimensions : 1920x1080 (résolution 1080p)
4. Cocher "Actualiser quand la scène devient active"

🧪 Tests des alertes

Testez les différents types d'alertes en ajoutant ?test=TYPE à l'URL :

  • ?test=follow - Tester un follow
  • ?test=subscription - Tester un abonnement
  • ?test=donation - Tester un don
  • ?test=raid - Tester un raid
  • ?test=bits - Tester des bits

🎨 Personnalisation avancée

Les overlays utilisent des variables CSS personnalisables dans css/organic-global.css. Vous pouvez modifier les couleurs, espacements, rayons de bordure et animations selon vos préférences.
